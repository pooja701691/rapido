## 🌟 About The Project

**Rapido** is a modern ride-booking platform that connects passengers with bike taxi captains through a seamless digital experience.

The application allows users to book rides, select pickup and destination locations, estimate fares, and manage their journeys. Captains can receive ride requests, accept bookings, and manage their rides efficiently.

The goal is to build a scalable, user-friendly transportation solution while implementing real-world full-stack development concepts.

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 Authentication | Secure user registration and login |
| 🏍️ Ride Booking | Book bike taxi rides easily |
| 📍 Location Selection | Select pickup and destination |
| 💰 Fare Estimation | Calculate estimated ride costs |
| 🚦 Ride Management | Manage ride requests and statuses |
| 👨‍✈️ Captain Dashboard | Accept and manage ride bookings |
| 📜 Ride History | Access previous ride details |
| 📱 Responsive UI | User-friendly interface |
